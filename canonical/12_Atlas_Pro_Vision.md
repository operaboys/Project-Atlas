# ابزارهای توسعه‌دهنده

## ویرایشگر کد (Pro v0.1)

### ویژگی‌ها
- Syntax Highlighting: بیش از ۵۰ زبان
- تکمیل خودکار: پیشنهادات بر اساس زمینه
- چندفایلی: ویرایش تبی
- نمای تقسیم: ویرایش کنار به کناف
- پیدا کردن و جایگزینی: پشتیبانی از Regex
- شماره خطوط: فعال/غیرفعال
- Minimap: نمای کلی کد
- تم‌ها: مطابق با تم‌های ترمینال

### عملکرد
- باز کردن فایل: کمتر از ۵۰۰ms
- ذخیره خودکار: هر ۳۰ ثانیه
- حداکثر اندازه فایل: ۱MB (هشدار برای فایل‌های بزرگتر)

## مرکز Git (Pro v0.1)

### ویژگی‌ها
- Clone: از URL
- Commit: با پیام و نویسنده
- Push: به ریموت
- Pull: از ریموت
- Branch: ایجاد، تغییر، حذف
- Merge: با حل تعارض
- Diff: نمایشگر تفاوت بصری
- Log: تاریخخه commit با نمودار

### رابط کاربری
- لیست مخزن‌ها
- انتخابگر Branch
- تاریخچه Commit
- نمایشگر Diff
- حل‌کننده تعارض

## مدیر SSH (Pro v0.2)

### ویژگی‌ها
- ذخیره اتصالات: Host, port, user, key
- مدیریت کلیدها: تولید، وارد کردن، خارج کردن
- ترمینال: ترمینال کامل SSH
- SFTP: انتقال فایل
- Port Forwarding: محلی، ریموت
- X11 Forwarding: برنامه‌های GUI

### امنیت
- کلیدها در Android Keystore ذخیره می‌شوند
- فقط اتصالات رمزگذاری شده
- تأیید کلید Host

## مرکز Package (Pro v0.2)

### ویژگی‌ها
- مدیر APT: جستجو، نصب، به‌روزرسانی، حذف
- اطلاعات Package: توضیحات، نسخه، وابستگی‌ها
- مدیریت مخزن‌ها: افزودن/حذف مخزن‌ها
- به‌روزرسانی همه: به‌روزرسانی با یک ضربه
- تاریخچه: تاریخچه نصب/به‌روزرسانی

### رابط کاربری
- لیست Package با آیکون
- جستجو با فیلترها
- دکمه‌های نصب/به‌روزرسانی
- نشانگرهای پیشرفت

## قالب‌های پروژه (Pro v0.3)

### قالب‌های موجود
- Python: Flask, Django, FastAPI
- Node.js: Express, Next.js
- React: Create React App
- Flutter: پروژه جدید
- Go: پروژه پایه
- Rust: پروژه پایه

### ویژگی‌ها
- ایجاد پروژه با یک ضربه
- قالب‌های سفارشی
- فروشگاه قالب (آینده)

## فضاهای کاری (Pro v0.3)

### ویژگی‌ها
- فضاهای کاری متعدد
- تغییر فوری پروفایل
- تنظیمات جداگانه برای هر فضا
- ترمینال‌های مشترک
- پشتیبانبازیابی فضای کاری
